# PRD: FinSight

## 목표
카드 명세서·은행 거래내역 CSV를 올리기만 하면, 형식에 상관없이 AI가 지출을 분류·요약하고 절약 포인트를 알려준다.

## 사용자
- 매달 카드 명세서를 받는 개인 (한국어/영어 사용자)
- 여러 카드·계좌를 쓰면서 전체 지출을 한눈에 보고 싶은 사람
- 새는 돈(잊은 구독, 중복 결제)을 찾고 싶은 사람

## 핵심 기능

### 1. 랜딩 페이지
- 제품 소개, 기능 설명, Free/Pro 요금제 비교, CTA(시작하기 → 회원가입)
- 로그인 상태면 CTA가 대시보드로 이동

### 2. 인증
- 이메일 + 비밀번호 (이메일 인증 필수)
- Google 소셜 로그인
- 비로그인 사용자가 `/dashboard` 접근 시 로그인 페이지로 리다이렉트

### 3. CSV 업로드 & 분석
- 형식 제한 없음: 카드사·은행마다 다른 컬럼 구조를 AI가 매핑 (날짜/금액/가맹점/설명)
- 파일당 최대 1,000행, 최대 1MB. 초과 시 업로드 거부 + 안내
- 인코딩: UTF-8, EUC-KR(CP949) 모두 지원 (국내 카드사 CSV 대응)
- 분석은 비동기 처리: 업로드 → "분석 중" 상태 → 완료 시 결과 표시
- 원본 CSV는 비공개 스토리지에 저장 (업로드 화면에 저장 사실 명시)

### 4. 대시보드 (분석 결과)

| 기능 | Free | Pro |
|------|------|-----|
| 업로드 | 분석 1건당 파일 1개 | 분석 1건당 파일 여러 개 (여러 카드/계좌 통합) |
| 카테고리별 지출 분류 + 차트 | ✅ | ✅ |
| 이번 분석 요약 (총지출, 상위 가맹점, 카테고리 비중) | ✅ | ✅ |
| 분석 기록 보관 | 최근 1건만 (새 분석 시 이전 것 삭제) | 전체 보관 |
| 여러 달 누적 비교 / 월별 추이 / 전월 대비 | — | ✅ |
| 정기결제 탐지 / 이상거래(중복·급증) 탐지 | — | ✅ |
| AI 인사이트 & 절약 조언 (자연어 리포트) | — | ✅ |
| 월간 분석 횟수 상한 (남용 방지) | 5회 | 50회 |

- Pro 전용 기능은 Free 사용자에게 잠금 상태로 노출하고 업그레이드 CTA를 표시

### 5. 결제 (Polar)
- Pro: $9/월 구독
- 업그레이드 → Polar Checkout → 완료 후 대시보드 복귀
- 구독 상태는 Polar 웹훅으로만 반영 (클라이언트 리다이렉트를 신뢰하지 않음)
- 설정 페이지에서 Polar 고객 포털로 이동 (구독 해지·결제수단 변경)

### 6. 설정
- 언어 전환 (ko/en)
- 내 데이터 전체 삭제 (원본 CSV + 거래내역 + 분석 결과)
- 구독 관리 (Polar 포털 링크)

### 7. 다국어
- 한국어/영어 UI (`/ko`, `/en`)
- AI 인사이트도 사용자 언어로 생성
- 금액은 CSV 원본 통화 그대로 표시 (환율 변환 없음)

### 8. 배포
- Vercel 프로덕션 배포 + Supabase 프로덕션 프로젝트 + Polar 프로덕션 연동

## 성공 기준
- 국내 주요 카드사 CSV 3종 이상 + 영문 은행 CSV 1종을 별도 설정 없이 분석 성공
- 1,000행 CSV 분석이 2분 이내 완료
- Free → Pro 결제 후 웹훅 반영까지 Pro 기능 즉시 해제
- 다른 사용자의 데이터에 접근 불가 (RLS 테스트로 검증)

## MVP 제외 사항
- 은행/카드사 API 직접 연동 (마이데이터, Plaid 등). CSV 업로드만 지원
- PDF·Excel(xlsx) 명세서 파싱
- 환율 변환, 다중 통화 합산
- 예산 설정·알림, 이메일 리포트
- 모바일 앱
- 팀/가족 공유 계정
- 사용자가 카테고리를 직접 수정하는 기능
- 연간 결제 플랜

## 디자인
- 라이트 모드 기본, 금융 도구다운 차분하고 밀도 있는 대시보드
- 무채색 + 포인트 컬러 1가지 (딥 그린). 상세는 `docs/UI_GUIDE.md`
