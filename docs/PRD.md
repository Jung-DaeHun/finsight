# PRD: FinSight

> 사용자 흐름은 `docs/USER_FLOW.md`, 구조·실행 계획·검증은 `docs/ARCHITECTURE.md`, 결정 이유는 `docs/ADR.md`.

## 목표
카드 명세서·은행 거래내역 파일(CSV/엑셀)을 올리기만 하면, 형식에 상관없이 AI가 지출을 분류·요약하고 절약 포인트를 알려준다. 프로토타입 수준의 MVP로 랜딩 → 로그인 → 분석 → 결제 → 배포까지 동작시킨다.

## 사용자
- 매달 카드 명세서를 받는 국내 개인 사용자 (한국어 UI, 원화 명세서)
- 여러 카드·계좌를 쓰면서 전체 지출을 한눈에 보고 싶은 사람
- 새는 돈(잊은 구독, 중복 결제)을 찾고 싶은 사람

## 핵심 기능

### 1. 랜딩 페이지
- 제품 소개, 기능 설명, Free/Pro 요금제 비교, CTA(무료로 시작하기)
- 로그인 상태면 CTA가 대시보드로 이동

### 2. 인증
- 이메일 + 비밀번호 (이메일 인증 필수, 다른 기기에서 연 인증 링크도 동작)
- Google 소셜 로그인
- 비밀번호 재설정
- 비로그인 사용자가 `/dashboard`·`/settings` 접근 시 로그인 페이지로 이동, 로그인 후 항상 `/dashboard`

### 3. 파일 업로드 & 분석
- 지원 형식: CSV, xlsx, xls(HTML 표 형식 포함), UTF-8·EUC-KR(CP949)
- 형식 제한 없음: 카드사·은행마다 다른 컬럼 구조를 AI가 매핑 (날짜/금액/가맹점/설명)
- 파일당 1MB, 시트 1,200행(제목·합계 포함). 초과 시 거부 + 안내
- 암호 걸린 엑셀은 해제 방법 안내
- 분석은 요청 한 번에 처리(동기). 로딩 화면 후 결과 페이지로 이동
- 원화(KRW)만 지원. 해외 결제는 원화 환산 금액으로 집계하고, 원화 금액이 없는 외화 명세서는 거부
- 같은 파일(내용 해시 기준)을 이미 분석했으면 거부
- 원본 파일은 비공개 스토리지에 저장 (업로드 화면에 저장 사실 명시)

### 4. 대시보드 (분석 결과)

| 기능 | Free | Pro |
|------|------|-----|
| 분석당 파일 수 | 1개 | 최대 3개 (여러 카드/계좌 통합) |
| 카테고리별 지출 분류 + 차트 + 거래 목록 | ✅ | ✅ |
| 이번 분석 요약 (총지출, 상위 가맹점, 카테고리 비중) | ✅ | ✅ |
| 정기결제 / 이상거래(중복·급증) 탐지 | 발견 건수만 (티저) | 상세 목록 |
| 월별 추이 / 전월 대비 | — | ✅ |
| AI 인사이트 & 절약 조언 | — | ✅ (결과 화면 버튼으로 생성) |
| 월 분석 횟수 (성공 기준, 삭제해도 복구 안 됨) | 5회 | 50회 |

- 파일이 없는 사용자를 위해 샘플 결과 체험 제공 (LLM 호출 없음)
- Pro 전용 기능은 Free 사용자에게 잠금 카드로 노출하고 업그레이드 CTA를 표시
- Free도 자신의 모든 분석을 열람한다. Pro로 전환하면 기존 분석의 탐지 상세·추이·인사이트 버튼이 즉시 열림

### 5. 결제 (Polar)
- Pro: $9/월 구독
- 업그레이드 → Polar Checkout → 대시보드 복귀 (반영 대기 시 "결제 확인 중" 후 자동 새로고침)
- 구독 상태는 서명 검증된 Polar 웹훅으로만 반영
- 해지 예약 시 기간 끝까지 Pro, 기간 종료 후 Free (과거 분석은 그대로 열람, Pro 기능만 잠김)
- 설정 페이지에서 Polar 고객 포털로 이동 (해지·결제수단 변경)

### 6. 설정
- 구독 상태 한 줄 표시
- 분석 개별 삭제
- 회원 탈퇴 (Polar 구독 취소 → 원본 파일 삭제 → 계정·데이터 삭제)

### 7. 배포
- Vercel CLI로 구현 단계마다 프로덕션 URL에 자동 배포
- Claude·Polar는 mock 모드로 먼저 배포하고, 실제 키가 준비되면 전환
- 가입 시 개인정보 국외 이전(Anthropic·Polar·Vercel) 동의

## 성공 기준
- 국내 주요 카드사 엑셀/CSV 3종 이상 + 은행 내역 1종을 별도 설정 없이 분석 성공
- Pro 최대 입력(3파일·3,600행) 분석이 240초 안에 완료
- 결제 후 웹훅 반영 즉시 Pro 기능 해제
- 다른 사용자의 데이터에 접근 불가, Free 사용자가 Pro 데이터를 API로 받을 수 없음
- 가설 H1~H8 (`docs/USER_FLOW.md`)을 기존 테이블 SQL과 페이지뷰로 측정 가능

## MVP 제외 사항 (의도적 결정)

| 뺀 것 | 대신 | 나중에 필요해지는 신호 |
|---|---|---|
| Storage 직접 업로드·비동기 처리·상태 폴링 | 요청 한 번에 동기 처리 (Pro 3개 × 1MB) | 더 큰 파일·파일 수 요구, 타임아웃 증가 |
| 영어 UI·다국어 | 한국어만 | 해외 사용자 유입 |
| 외화 명세서·환율 변환·다중 통화 | KRW 전용, 원화 금액 열이 없으면 거부 | 외화 결제 비중이 큰 사용자 |
| 후보 거래행·컬럼·셀 단위 세부 상한 | 1MB + 시트 1,200행 상한 하나 | 대용량 파일 요구 |
| 분석 결과 조회 API | 결과 페이지(Server Component)가 `lib/data` 직접 호출 | 모바일 앱·외부 연동 |
| Free 이전 분석 잠금 | Free도 모든 분석 열람, Pro는 기능으로만 구분 | Pro 전환율 저조 |
| 이벤트 수집 테이블, 분류 피드백 버튼 | SQL + 인터뷰 | 사용자 수 증가 |
| DB 통합 테스트 환경(로컬 Supabase·Docker, pgTAP) | Supabase **개발용 클라우드 프로젝트**에 대해 권한 차단·완료 RPC만 자동 테스트, 나머지는 단위 테스트 + go-live 단계 수동 체크리스트 | 정책·RPC가 늘어날 때 |
| 분석 간 거래 중복 제거 | 같은 파일 재업로드만 차단 | 이중 집계 문의 |
| 사용자당 병렬 분석·작업 큐·사용량 예약 상태 관리 | 부분 unique index로 사용자당 처리 1건, 성공만 기록하는 사용량 원장, 6분 정체 복구 | 처리량 확대 요구 |
| CSP, Origin 검사, CAPTCHA | 기본 보안 헤더, SameSite, 이메일 인증 | 봇 가입·공격 징후 |
| 로그인 후 원래 경로 복귀 | 항상 `/dashboard` | – |
| 데이터 전체 삭제(계정 유지), 앱 내 결제 상태 배너 | 회원 탈퇴 + 개별 삭제, 설정의 상태 한 줄 | 요청 발생 시 |
| 은행 API 연동(마이데이터·Plaid), PDF, 첫 시트 외 시트 선택, 예산·알림, 이메일 리포트, 카테고리 수정, 연간 플랜, 팀/가족 공유 계정, 모바일 앱 | – | – |

## 디자인
